Icon artwork in this directory is derived from
[Lucide](https://lucide.dev) (v1.48.0), fetched from `lucide-static`.

The geometry is Lucide's; it has been re-serialised into this repository's
single-line form with presentation attributes hoisted onto the root `<svg>`
(`stroke="currentColor"`, `stroke-width="1.7"`, round caps and joins) so the
set renders consistently through gpui-kit's icon system. No path data has been
altered.
